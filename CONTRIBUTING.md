# Contributing

Thank you for your interest in contributing to geekspe. This document outlines the process for submitting changes.

## How to Contribute

1. **Fork** the repository on GitHub
2. **Clone** your fork locally
3. **Create a branch** for your changes: `git checkout -b feature/your-feature`
4. **Make your changes** and test locally
5. **Commit** with a clear, concise message
6. **Push** to your fork: `git push origin feature/your-feature`
7. **Open a Pull Request** against the `main` branch

## Development Setup

See [README.md](README.md) for local development instructions.

## Pull Request Guidelines

- Keep PRs focused on a single feature or fix
- Describe what changed and why in the PR description
- Ensure the development server runs without errors
- Update documentation if your changes affect setup or usage

## Code Style

- Follow PEP 8 for Python code
- Use 4 spaces for indentation
- Keep templates clean and readable

## Reporting Issues

If you find a bug or have a suggestion, [open an issue](https://github.com/elxecutor/geekspe/issues) with:

- A clear title and description
- Steps to reproduce (for bugs)
- Expected vs actual behavior
- Screenshots if applicable

## Code of Conduct

By participating, you are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md).
